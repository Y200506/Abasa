# Olivia Sigamoney | Absa Consultant

A mobile-friendly contact page for Olivia Sigamoney, an Absa consultant. People can tap to message her on WhatsApp, email her, call her, save her details to their phone, or scan a QR code that opens the page.

Built with plain HTML, CSS and JavaScript (no frameworks).

## What's inside

| File | What it does |
| --- | --- |
| `index.html` | The page content |
| `style.css` | Colours, fonts and layout |
| `script.js` | Builds the QR code, download button and share button |
| `olivia-sigamoney.vcf` | The "Save to my contacts" file |
| `images/` | Portrait and Absa logo |

## Run it on your computer

Open `index.html` in your browser. The QR code only appears once the site is online.

## Put it online (GitHub Pages)

1. Push this project to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Branch**, choose `main` and `/ (root)`, then **Save**.
4. After a minute, your link appears at the top of that page.

## Change the details

- Phone, email and WhatsApp links are in `index.html`.
- Colours are at the top of `style.css`.
- After the site is live, you can paste its address into `SITE_URL` at the top of `script.js`.
